How the experiment collects, searches, and evaluates

The configuration is fixed as A1–V1–A2, but execution is conditional: V1 may stop the online workflow before A2. Offline search never invents or removes calls; it replays the saved outcome and realized cost of each online execution.

Online API Offline replay Outcome
Online early stopping The V1 decision prevents an A2 API request immediately during development or reserved-test execution.
Offline replay Search operates on saved records. It makes no API calls and never recalculates the V1 branch.
Search unit Each arm is one complete fixed A1–V1–A2 configuration, not an individual solver or verifier.
Held-out boundary Only the frozen winner is collected on reserved test; those outcomes cannot influence model selection.
Recorded development calls: 2,700 A1 + 2,700 V1 + 1,285 A2 = 6,685 total Recorded reserved-test calls: 100 A1 + 100 V1 + 51 A2 = 251 total
